# Checking for Pythons
---
The first thing to do is check if Python is installed

## Mac and Linux

Open a Terminal and run

``` sh
python --version
```

or

``` sh
python -v
```

If it comes back with python 2.##.##, try

``` sh
python3 --version
```

## Windows

Open CMD and run

``` sh
python --version
```

or

Open PowerShell and run (not in video)

``` sh
py -v
```

# Interactive Prompt
---
now that python is install open a Terminal or command prompt run

```
python
```

this will get you to get a Interactive Prompt.

You can tell you're in the prompt by the >>>

**Interactive Prompt** let you write 1 line of python at a time. (it's like run ad hoc commands )

``` python
print('hello World')
```

hello World

``` python
x=10
print(x)
```

10

The Interactive Prompt is good for testing python command
you can tell you're in the prompt  

Exit
to exit the Interactive Prompt enter 

``` python
exit()
```
