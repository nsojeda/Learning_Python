# Variable Naming Conventions
---
## Conventions

- Variables are usually all lowercase
- If a Variables has multiple words then we separate those with underscore
- variable names should be as descriptive as possible

``` python
# "by convention our variables are usually all lowercase"

message = "Hello World"

# "if it's multiple words then we separate those with underscore"

my_message = "Hello, Nick!"

# variable names should be as descriptive as possible. As to what values they're meant to hold so message is a good variable name here because it's holding our message

print(message)

print(my_message)
```
